Beginner's guide

How to use Atlas

Atlas is a read-only map of this repository. It reads code and answers questions with a local model. Nothing is uploaded and nothing is changed.

  1. 1

    Open a file

    Browse Files on the left or type in Filter files by name. Click a file to read it with line numbers on the right.

  2. 2

    Ask a question

    Type a plain-English question in the box above and press Ask. The local model can take a minute. Answers cite the code they used.

  3. 3

    Follow a citation

    Blue links such as src/atlas/answer.py:113-155 jump to the exact lines. Every citation is checked against the index before it is shown.

  4. 4

    Explore the module map

    Switch between File and Package, click any box to open that file, and press Expand for a full-screen map. Press Esc to restore it.
