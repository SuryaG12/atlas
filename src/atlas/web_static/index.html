Guide / 4 steps

How to use Atlas

Atlas is a read-only index of this repository. It finds locations instantly, explains one file at a time, and can ask a local model about the whole repo. Three panes stay visible: search and files on the left, the editor and Ask in the middle, modules, citations, and model state on the right.

local

No upload. Atlas runs on your machine.

There is no sign-in, no hosted project, and no place to paste a repository. Atlas reads the folder it was started in, calls a model on your own machine, and never writes to the repo.

  1. 1

    Search the index

    The Search section at the top of the left rail reads paths, symbols, and code with the index alone. Results open at the exact path:line in milliseconds. Press / to focus it; press Esc to clear it. Files below is the same index as a tree.

  2. 2

    Open a file and explain it

    Open a path, then press explain this file in the work-pane header. The answer moves to the Editor / Ask tabs and uses only that file's code, so it stays focused. Use find, or Ctrl+F, to locate a line before you ask.

  3. 3

    Ask the repo

    The Ask tab takes cross-file questions. It calls the local model and can take a minute; the muted badge marks it as the slow path. The same action is available from the left rail with reasoning? ask the repo.

  4. 4

    Follow citations and modules

    Every citation is checked against the index first, then shown as a link in both the answer and the Citations list on the right. Click one to open its file at the cited lines. Modules opens as a package-grouped list; switch to Map only when you want import lines.

Press Esc to close this guide.
